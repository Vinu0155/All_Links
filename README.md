# 🔗 Personal Links & Portfolio Website

A modern, responsive **personal links and portfolio website** built with **HTML, CSS, and JavaScript**.
The project provides a clean profile page where visitors can quickly access important professional links, projects, contact information, and social profiles.

## ✨ Features

* 👤 Personal profile section
* 🔗 Multiple social and professional links
* 📱 Fully responsive design
* 🌙 Light/Dark theme toggle
* 💎 Animated floating crystal background
* ✨ Animated crystal ticker
* 🎨 Modern glassmorphism-style UI
* 🖱️ Hover and click animations
* 📂 Project information section
* 📞 Contact information section
* ♿ Reduced-motion support for accessibility
* ⚡ Lightweight single-page website
* 🎯 Mobile-friendly layout

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, animations, responsive design
* **JavaScript** – Interactive functionality
* **Font Awesome** – Icons
* **Google Fonts (Inter)** – Typography


## 🎨 Design

The website uses a modern dark interface with:

* Glass-like cards
* Rounded corners
* Gradient backgrounds
* Soft shadows
* Green accent colors
* Animated background elements
* Responsive sizing for mobile devices

The main page is designed around a centered profile card with a maximum width of approximately 500px.

## 💎 Animated Crystal Background

The website includes an animated crystal background effect. Crystal elements are generated and animated using CSS properties such as:

* `clip-path`
* `linear-gradient`
* `drop-shadow`
* CSS keyframe animations
* Custom CSS variables

The project also includes support for users who prefer reduced motion.

## 🌗 Theme Toggle

A theme toggle button is included in the interface, allowing the website to switch between dark and light visual themes.

The light theme changes the background, card, button, text, and muted-text variables using CSS custom properties.

## 📱 Responsive Design

The website is designed to work across different screen sizes.

A mobile media query adjusts:

* Page padding
* Card spacing
* Border radius
* Heading size

This makes the interface suitable for both desktop and mobile devices.

## 🚀 How to Run

### 1. Clone the repository

```bash

```

### 2. Open the project

```bash
cd YOUR-REPOSITORY
```

### 3. Run the website

Simply open:

```text

```

in any modern web browser.

## 🌐 Deployment

This project can easily be deployed using:

* GitHub Pages
* Netlify
* Vercel
* Any static web hosting service

### GitHub Pages

1. Upload the project to GitHub.
2. Open the repository's **Settings**.
3. Go to **Pages**.
4. Select the required branch.
5. Select the root folder.
6. Save the configuration.
7. GitHub will provide the published website URL.

## 🧩 Customization

You can customize the website by editing `index.html`.

### Change Profile Information

Update the profile name, role, and biography in the profile section.

### Change Colors

The main colors are controlled through CSS variables:

```css
:root {
    --bg: #07171e;
    --card: #203841;
    --btn: #536b74;
    --btn2: #627b84;
    --text: #f7fafb;
    --muted: #b9c5c9;
    --accent: #7ee7c2;
}
```

### Add or Change Links

Update the link buttons to point to your:

* GitHub
* LinkedIn
* Portfolio
* Resume
* Email
* Other professional profiles
